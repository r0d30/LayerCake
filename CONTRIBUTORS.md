## How to Contribute

1. **Code Contributions**: Submit pull requests with clear descriptions
2. **Bug Reports**: Use GitHub issues with detailed reproduction steps  
3. **Documentation**: Help improve guides, examples, and API docs
4. **Testing**: Create test cases and report compatibility issues
5. **Community**: Help other users in forums and discussions
